# 件名だけでなく、投稿者と状態も確かめる

JDK 17で、展開したこのフォルダから実行します。依存ライブラリ、Webサーバー、DBは使いません。

```sh
java DraftTitleReviewDemo.java
```

架空の問い合わせ1件を使います。件名はUnicodeコードポイントで1〜100と決め、投稿者本人が下書きだけを更新できる仕様です。`editBefore` は件名の長さだけを確認し、`editAfter` は投稿者IDと状態も確かめます。`actorId` はアプリが認証済みの利用者から得たIDを想定します。対象の問い合わせは特定済みで、不存在の場合の扱いや、権限の有無でHTTP応答を分けるかは決めていません。

- 自分の下書きは1文字・100文字なら保存成功が1回です。null、空、101文字は保存処理を呼びません。
- 他人の下書きや自分の受付済み・対応中・完了に対し、修正前は保存します。修正後は保存試行も成功も0回です。
- 保存失敗では試行1回、保存成功0回、結果は`SAVE_FAILED`です。`UPDATED` のときだけ成功を表示する前提なので、この結果では成功表示はfalseです。記録用の保存先は書き込む前に失敗し、既存の件名は保持します。

画面・HTTP応答・認証そのもの・実DBの確定や並行更新は扱いません。出力は認可と保存境界の説明用です。元の疑似コードに対応する不具合版は試験用で、実システムへ組み込むためのコードではありません。
