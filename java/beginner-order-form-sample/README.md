# Java基礎ガイドの注文フォーム練習

1. ZIPを展開し、`order-form.html` をブラウザで開きます。開発環境やサーバーの起動は不要です。
2. 個数を `2` にして「注文する」を押します。「送信予定の値」に `productId=1&quantity=2` が表示されます。注文は送信されません。
3. 見出しや入力条件を変えるときは、`order-form.html` をテキストエディターで開き、上書き保存してからブラウザを再読み込みします。

## 表示と送信予定の値を比べる

- `label` 内の「個数」を「注文数」に変え、同じ個数で押します。表示は変わり、送信予定の値の名前は `quantity` のままです。
- 「1〜10個」を「1〜5個」、入力欄の `max="10"` を `max="5"` に変えます。`5` では `quantity=5` が表示され、`0` と `6` ではブラウザが入力を止めます。
- `button { margin-top: 1rem; }` の `1rem` を `2rem` にすると、入力欄とボタンの幅をそろえたまま、ボタンの上の余白が広がります。

フォームとCSSは記事掲載のコードです。ファイル末尾のJavaScriptは、ブラウザの標準送信を止めて送信予定の値を表示するための練習用です。
