# Javaのブレークポイントで注文明細の合計を調べる

JDK 17を使います。ZIPを展開し、`OrderTotal.java` のあるディレクトリで実行してください。

```sh
javac -encoding UTF-8 -g OrderTotal.java
java OrderTotal
```

各行は「変更前 / 変更後」です。

```text
3件: 300 / 1500
0件: 0 / 0
1件: 500 / 500
```

## 更新行で止めて値を比べる

IDEで `OrderTotal.java` を開き、`sumBefore` の14行目にブレークポイントを置きます。`main` をデバッグ実行して最初の停止から1回再開すると、同じ行の2周目で止まります。

- 実行前の `i` は `1`、`total` は `500`、`linePrices[i]` は `700` です。
- ステップオーバーで更新行を1行進めると、`total` は `700` になります。500円が上書きされている箇所です。
- 修正後も調べるときは、14行目のブレークポイントを外し、`sumAfter` の22行目に置いて `main` をデバッグ実行し直します。2周目で `+=` の行を進めると、`total` は `1200` になります。

行番号は配布したファイルのものです。コピーしたコードに空行などを追加した場合は、メソッド名と代入式を目印にしてください。
