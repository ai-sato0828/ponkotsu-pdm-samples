# Javaのenumで出荷後のキャンセルを防ぐ

JDK 17以上、Maven。初回の依存取得にはネット接続が必要です。ZIPを展開し、pom.xmlのある場所で実行します。

```sh
mvn clean test
```

8件が成功します。内訳は、setter版の不具合を観測する1件、初期状態1件、未出荷から出荷・キャンセルできる2件、禁止操作で例外が出て状態が変わらない4件です。

`BrokenOrder` は不具合を見せるための旧版です。`Order` では状態を直接指定せず、`ship()` または `cancel()` を呼びます。状態確認を外すと禁止操作の4件が失敗します。状態を更新してから例外を投げるように順序を崩すと、異なる状態への禁止操作2件が失敗します。

この例の注文は未出荷から始まり、一度出荷・キャンセルしたら同じ操作の再送も拒否します。返品、発送取消、権限、保存、並行更新は扱いません。
