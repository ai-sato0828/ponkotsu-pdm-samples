# 同じ注文から、for文とStreamで対象を抽出する

JDK 17を用意し、展開したフォルダで実行します。サンプルは1ファイルで、外部ライブラリは使いません。

```sh
java OrderFilterDemo.java
```

入金済み、期限切れ、10,000円以上の条件をすべて満たす注文を、入力の順に取り出します。6件のうち、注文42と14がこの順で残ります。注文61の9,999円は対象外で、注文42の10,000円は対象です。

Streamは対象を抽出し、for文は対象に加えて最初の除外理由も記録します。未入金・期限内・金額不足が重なる注文95では、最初に確認する未入金を記録します。空の入力は空の結果です。

抽出結果に追加する契約があるときは、Streamで `Collectors.toCollection(ArrayList::new)` を使うと、for文と同じく可変の一覧を作れます。`Stream.toList()` の一覧は追加できません。サンプルは、追加しても元の一覧の内容が変わらないことを確かめます。
