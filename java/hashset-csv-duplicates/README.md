# HashSet.addでCSVの未入力と重複を分ける

JDK 17とMaven 3を使います。ZIPを展開し、`pom.xml` のあるフォルダで `mvn test` を実行します。

- 同じ会社コードと社員番号の組み合わせを2回追加すると、2回目の `add` は `false` を返し、要素は1つだけ残ります。
- 注文番号が `null`、空文字、空白だけの行はすべて必須エラーです。有効な注文番号が繰り返されたときにだけ重複として扱います。キーの前後空白や大文字小文字は変換していません。
- エラーの位置には読み取り時に保持したレコードの開始行番号を使います。3番目のレコードがファイルの5行目で始まる例で、重複の位置は5行目です。

サンプルでは読み取り済みの `CsvRow` を使います。CSVファイルのパースとDBへの登録は扱いません。必須チェックを外すと、空欄の2件目が重複と判定されます。行番号をヘッダー込みの添字で代用すると、5行目が4行目と報告されます。
