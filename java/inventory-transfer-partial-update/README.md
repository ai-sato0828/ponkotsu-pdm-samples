# Javaの在庫移動で片方だけ減る原因

JDK 17以上とMavenを使います。初回の依存取得にはネット接続が必要です。ZIPを展開し、pom.xmlがある場所で実行します。

```sh
mvn clean test
```

JUnitは7件成功します。移動元8、移動先9、上限10で2個移すと、旧版の `BrokenInventory` は例外の後に6と9になります。修正版の `Inventory` は8と9を維持し、その後1個に減らして呼び直すと7と10になります。

移動先の空き容量を確認する直前に `levels = new StockLevels(before.source() - units, before.destination());` を挿入すると、容量不足後の在庫保持と、数量を減らして呼び直すテストの2件が失敗します。

このサンプルは1スレッドのJavaオブジェクト内で、決められた2か所のうち移動元から移動先へ動かす処理です。DB更新、並行処理、通知、同じ成功操作の重複防止は対象外です。
