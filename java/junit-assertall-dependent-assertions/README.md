# JUnit 5のassertAllで前提に依存する検証をまとめる

JDK 17とMavenを使います。初回の依存取得にはネット接続が必要です。ZIP展開後、pom.xmlがあるディレクトリで実行します。

```sh
mvn clean test
```

テスト対象はQuoteCalculator.javaとQuote.java、比較と回帰テストはQuoteAssertionsTest.javaです。JUnit Jupiter 5.12.2で4件実行します。

- 配送なし・合計4,200円の見積を3ラムダで検証すると、合計違い・配送情報なし・NullPointerExceptionの3件を報告します。
- 同じ見積を2ラムダで検証すると、配送情報なし・合計違いの2件を報告します。
- 配送方法がEXPRESSで合計4,700円の見積では、配送方法違いの1件だけを報告します。
- 配送方法がSTANDARDで合計4,700円の見積では、すべての条件を満たします。

最初の3テストは、比較のためにアサーションの報告内容を捕まえます。実際の確定見積を検証するテストでは、修正版のassertAllを通常どおり直接呼びます。このサンプルの計算は、配送が未入力の暫定見積も返す小さなモデルです。配送サービスの実際の運賃や、業務アプリの確定処理は扱いません。
