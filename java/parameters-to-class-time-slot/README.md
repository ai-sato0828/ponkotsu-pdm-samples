# 開始時刻と終了時刻から考えるJavaのクラス設計

JDK 17以上とMavenで実行します。初回の依存取得にはネット接続が必要です。

```sh
mvn clean test
```

`ReservationChecks` は開始・終了を別々に渡す版、`TimeSlot` は成立条件つきで2つを持つ版です。時刻は同じ日付を前提とし、終了時刻は範囲に含めません。深夜をまたぐ予約や実際の登録、同時予約の排他制御はこの例の範囲外です。

`TimeSlotTest` は変更前後で同じ結果を確認する9件、`RoomScheduleTest` は会議室ごとの条件を確かめる3件です。

上限を60分から90分に変更する場合は `new RoomSchedule(90, ...)` のように、会議室の設定から渡す値を更新します。時刻の前後関係は `TimeSlot` のままです。逆に終了と開始が同じ時刻を重なりと判定する変更を入れると、隣り合う予約のテストが失敗します。
