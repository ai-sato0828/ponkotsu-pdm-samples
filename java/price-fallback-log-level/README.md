# 価格APIがタイムアウトしたときのログを再現する

JDK 17とMaven 3を使います。展開したフォルダで次を実行します。

```sh
mvn compile exec:java
```

- APIが1,200円を返した場合はステータス200で価格1,200円を返します。WARN・ERRORは記録しません。
- APIがタイムアウトし、利用できるキャッシュが1,100円の場合はステータス200で価格1,100円を返し、WARNを1件記録します。
- APIがタイムアウトし、利用できるキャッシュが空の場合はステータス503で価格を返さず、元の例外とリクエストID付きのERRORを1件記録します。

APIとキャッシュの結果は差し替えて検証します。実際のHTTPサーバーやキャッシュは起動せず、Logbackが受け取るイベントと、HTTPステータスに対応する戻り値を比較します。Logbackを呼ぶ2メソッドは記事のWARN・ERRORの例と同じです。

失敗を再現するときは `PriceLookup.findPrice` で `log.warn(...)` を `priceCache.findFresh(productId)` より前へ移します。代替値がない要求でWARNとERRORの両方が記録され、3番目のケースが失敗します。
