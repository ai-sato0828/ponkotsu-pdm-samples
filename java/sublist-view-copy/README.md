# JavaのsubListで元のListまで変わる理由

JDK 17以上とMavenが必要です。初回は依存取得にネット接続が必要です。ZIPを展開し、pom.xmlのあるディレクトリから実行します。

```sh
mvn clean test
```

9件が成功します。`BrokenDispatchPreview` では、先頭2件の表示用一覧を並べ替えると、元の処理待ちリストまで順序が変わります。`DispatchPreview` は取り出した範囲をArrayListにコピーしてから並べ替えます。

修正版から `new ArrayList<>(...)` を外すと、元の処理順を確認するテストと、リストを別々に編集できることを確認するテストが失敗します。

入力はnullを含まない文字列の一覧です。コピーはリストの順序と要素の出し入れを独立させます。要素が可変オブジェクトで、その内容も別々に更新したい場合は要素のコピーを設計します。
