# Spring MVCの入力検証の再現

JDK 17とMaven 3.9系を用意し、`mvn test` を実行します。Spring Boot 3.5.16のMVCとBean Validationを対象とし、テスト用アプリにDBはありません。

| 記事ID | 検証 |
|---|---|
| 2285 | JSONの構文不正、項目制約違反、項目に属さない相関制約を別の応答として確認 |
| 2283 | List要素へのValidを外した場合の204、子の制約違反400、null要素のエラーパス |
| 2248 | 同日204、終了日が前なら400、未入力400。終了日項目に紐付けたエラー |
| 1740 | 必須クエリ欠落、空白、型変換の3つの例外型と正常時200 |
| 1233 | URL変数31／32／33文字と、ルーティングが一致しない404 |

検証条件と期待値は `ValidationContractsTest.java` に対応します。APIはバリデーションを確認する例で、実データは保存しません。
