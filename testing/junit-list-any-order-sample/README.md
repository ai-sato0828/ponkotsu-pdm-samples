# 出荷CSVの明細行を順不同かつ重複込みで比べる

JDK 17、Maven 3.9系、JUnit Jupiter 5.12.2、AssertJ 3.27.7、Surefire 3.5.3を使用します。ZIPを展開し、`pom.xml` のある場所で `mvn test` を実行します。初回はMavenが依存を取得できる環境が必要です。

`ShipmentCsv.dataRows` は、検証済みの商品コードと数量からヘッダーなしのデータ行を返します。別梱包なら、同じ商品コードと数量でも1梱包につき1行です。テストデータでは `SKU-100,1` が2行、`SKU-200,1` が1行必要で、行順は問わない契約です。実際のCSVファイル入出力、ヘッダー、改行、任意文字列のエスケープはこのサンプルの範囲外です。

通常はテスト6件が成功します。 `ShipmentCsv.java` の `.map(...)` と `.toList()` の間に `.distinct()` を追加して実行すると、通常の出力を重複込みで比較する1件が失敗します。その状態でも、旧比較の `HashSet` と `containsOnly` は欠落したデータを合格にすることを再現用テストで確認できます。変更は別の展開先で行ってください。

- `ShipmentCsv.java` はテスト対象。
- `ShipmentCsvTest.java` は順序、重複の不足・余分、誤合格を確かめるテスト。
- `pom.xml` はテストの依存関係と実行設定。
