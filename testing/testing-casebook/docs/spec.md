# 固定した学習用仕様

この仕様の期待値は実装から生成していません。架空の問い合わせ管理の仕様です。

- TITLE-01: null、空文字、空白のみ（String.isBlankの意味）の件名は拒否する。
- TITLE-02: 空白のみでなければUnicodeコードポイント数1〜100を許可し、101以上は拒否する。書記素クラスタや見た目の幅ではない。
- TITLE-03: 前後空白をtrimせず数える。a×99＋空白は100として許可し、a×100＋空白は101として拒否する。
- START-01: RECEIVEDかつ担当者IDと操作ユーザーIDが一致するときだけ開始成功。IN_PROGRESSへ遷移する。
- START-02: それ以外はfalseを返し、状態も作成者も担当者も変更しない。

creatorId=10、担当ありのときassigneeId=20。作成者であるだけでは開始を許可しない。担当未設定はnull。状態はDRAFT/RECEIVED/IN_PROGRESS/COMPLETED。状態nullは生成時拒否し、20ケースの対象外。
